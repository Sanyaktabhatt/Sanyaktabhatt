Async FastAPI service tracking AI-agent health via heartbeats, with LLM diagnosis of errors (schema-validated JSON, fallback, LRU+TTL cache, retry with backoff) and a 4-agent briefing pipeline.

**🎯 84.4% category accuracy** vs 73.3% keyword baseline
